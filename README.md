# Martix-Operation

🔢 Project Overview

The Matrix Operations project is a C programming project that performs basic operations on matrices. The program allows the user to perform matrix addition, matrix multiplication, and matrix transpose using two-dimensional arrays, loops, functions, and a menu-driven approach.

🎯 Objective

To implement basic matrix operations using C programming.
To understand and use 2D arrays.
To perform matrix addition and multiplication.
To find the transpose of a matrix.
To practice functions, loops, and switch-case statements.

⚙️ Technologies Used

C Programming
Code::Blocks
GCC/MinGW Compiler
2D Arrays

🔄 Project Workflow

Enter Matrix → Select Operation → Process Matrix → Perform Calculation → Display Result

✅ Result

The program successfully performs matrix addition, multiplication, and transpose operations and displays the calculated matrix results based on the user's choice.
